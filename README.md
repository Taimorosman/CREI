# Joudah Al-Ibtkar (JIC) — Official Website

A bilingual (English / Arabic, with full RTL) marketing website for **شركة جودة الابتكار المحدودة (Joudah Al-Ibtkar Limited / JIC)** — providing advanced decorative and construction chemical solutions across the Kingdom of Saudi Arabia. Built with Next.js, React, TypeScript, and Tailwind CSS.

## Pages

| Route | Description |
| --- | --- |
| `/` | **Home** — Hero, company intro, values, systems grid, sample CTA, partners, newsletter |
| `/about` | **About** — Story, stats, corporate values, CTA |
| `/services` | **Services** — 10 engineered systems, 4-step process, sample request form |
| `/products` | **Products** — 5 categories, technical documents CTA, full catalog downloads |
| `/brands` | **Brands** — 6 partner brand cards (CCC, RapidSet, Flake, Bricform, Lythic, Day1) |
| `/contact` | **Contact** — Regional presence, full form, interactive SVG coverage map |

## Highlights

- **Bilingual (English & Arabic)** with seamless toggle and full right-to-left (RTL) layout.
- **Modern typography**: Inter & Space Grotesk (Latin) and IBM Plex Sans Arabic.
- **Curated dark theme**: High-contrast, emerald-accented engineering aesthetics.
- **Fast, responsive performance**: High-fidelity visual cards, SVG interactive components, and zero unnecessary client bloat.
- **Full SEO & OpenGraph**: Customized metadata for Saudi Arabia search visibility.

## Getting Started

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm run start    # serve the production build
```
